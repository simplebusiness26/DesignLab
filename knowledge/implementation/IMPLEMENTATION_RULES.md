# Implementation Rules

- Do not redesign approved UX while coding.
- Do not invent functionality or backend behavior.
- Reuse approved components and tokens.
- Preserve existing backend contracts and permissions.
- Flag impossible requirements instead of silently changing the design.
- Keep keyboard, safe area, dynamic type and accessibility behavior correct.
- Prefer maintainable reusable code over one-off pixel fixes.
- Record approved deviations.
- Use visual/interaction QA after implementation.
