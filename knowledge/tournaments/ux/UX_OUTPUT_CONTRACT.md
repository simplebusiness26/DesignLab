# UX Output Contract

Every contestant returns:
1. Concept name
2. User job
3. Core UX idea
4. Screen/flow structure
5. Information hierarchy
6. Navigation
7. Primary interactions
8. Gesture/accelerator interactions
9. Feedback/motion behaviour
10. Populated state
11. Empty state
12. Loading state
13. Error state
14. Keyboard behaviour
15. Accessibility
16. Product-truth verification
17. Implementation considerations
18. Strengths
19. Trade-offs
20. Interactive prototype specification

Do not spend output on biographies or design-theory essays.
