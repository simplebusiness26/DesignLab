# Visual Design Tournament Rules

Contestants:
1. LocalThunk-inspired delight lens
2. Tobias van Schneider-inspired art-direction lens
3. Raja Vijayaraman-inspired future-facing utility lens
4. Devin Davies-inspired clarity lens

## Inputs
Every contestant receives:
- identical locked Final UX Spec;
- identical Brand Constitution;
- identical hero-screen set;
- identical platform/accessibility constraints.

## Hard boundary
Visual designers may alter visual hierarchy, typography, colour, surfaces, depth, icon treatment, imagery and motion aesthetics **without changing approved functionality or navigation**.

If a visual idea requires UX change, label it and exclude it until UX is reopened.

## Sequence
1. Sonnet applies each visual persona and writes a focused brief/spec.
2. Fable renders only the hero-screen visual work that benefits from specialist visual capability.
3. Human reviews four visual directions.
4. Human preferences are recorded.
5. Opus/visual synthesis produces one coherent design system.
6. Human reviews final visual design.
7. Visual design locks on explicit approval.
