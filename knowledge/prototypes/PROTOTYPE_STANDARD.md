# Prototype Standard

UX tournament prototypes are **disposable interaction experiments**, not production apps.

## Must demonstrate
- navigation;
- core taps;
- important gestures plus visible alternatives;
- scroll behavior;
- sheets/menus;
- keyboard movement;
- loading, empty, error and populated states;
- representative long content;
- transitions relevant to comprehension;
- accessibility assumptions.

## Does not require
- real production backend;
- production security architecture;
- complete app;
- final visual polish;
- full analytics;
- production deployment.

The prototype exists to let the user judge how the concept works before paying to build it for real.
