# Xplorer Messages — Synthetic Validation Feature Packet

> Validation fixture only. This is based on conversation-authorised capabilities and is **not** a substitute for repository-derived Xplorer Product Truth.

## User job
Find the right conversation quickly, continue it without losing context, and access existing message boards from the same messaging area.

## Authorised capabilities in fixture
- friend direct messages;
- manager messages;
- existing message boards;
- unread state;
- open conversation/thread;
- compose and send.

## Known problem
The message composer must move above the software keyboard rather than being covered by it.

## Test constraint
Personas may reorganise and improve interaction but may not invent AI classification, new backend messaging types, new moderation systems or unverified notification capabilities.
