# Quiet Campfire — Interactive Prototype Spec

Frames:
1. Messages — populated.
2. Messages — selected category/filter.
3. Thread — keyboard closed.
4. Thread — keyboard open.
5. Send pending.
6. Send failure/retry.
7. Empty state.

Required interactions:
- open/close thread;
- switch existing message category/organisation;
- scroll list and thread;
- open keyboard and keep composer visible;
- send representative message;
- recover from send failure;
- demonstrate any persona-specific accelerator with a visible equivalent.

The prototype does not require a real backend. It must demonstrate behavior sufficiently for human comparison.
