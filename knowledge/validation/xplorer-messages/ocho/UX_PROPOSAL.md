# Quiet Campfire

## Persona
Ocho studio / grug lens

## Core thesis
Reduce the inbox to a calm human conversation surface. Use one strong list, restrained category access, clear unread state and a thread where the conversation dominates.

## Structure
- Messages landing surface with Friends, Managers and Message Boards available through a clear organisation pattern.
- Conversation rows show identity, useful preview, timestamp/recency and unread state.
- Thread keeps conversation history dominant.
- Composer remains pinned immediately above the software keyboard.

## Primary interaction
Tap a row to open the thread. Back returns to the same list context/scroll position.

## Persona-specific treatment
- Treat reduction as an active design move: if controls compete with the human moment, first ask what can disappear or become contextual.
- Use personality in service of comprehension and emotional ease, not as decorative noise.
- Small moments of surprise can carry more delight than constant visual stimulation.
- A deliberately narrow feature surface can be a strength when it makes the core experience feel authored and memorable.

## Required states
Populated, empty category, loading, send pending, send failure, long message, keyboard open, reduced motion.

## Accessibility
Important actions have visible alternatives; no state depends only on colour or gesture.

## Trade-off
This direction intentionally optimises radical prioritisation and may sacrifice some of the strengths offered by the other persona lenses.

## Product-truth check
No new backend capability is required by the primary proposal.
