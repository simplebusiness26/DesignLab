# DesignLab 2.0 Knowledge System

DesignLab 2.0 separates deep research from runtime context.

## Core pipeline

`evidence → research dossier → compact persona pack → product truth → feature packet → independent tournament → Perfect-10 gate → human selection → synthesis → approval lock → implementation → QA`

## Runtime rule

Never load the whole research archive into a routine model call. Load only:
- the relevant `PERSONA_PACK.md`;
- `PERSONA_PERFECT_10_GATE.md`;
- the smallest relevant slice of Product Truth;
- the current Feature Packet;
- relevant brand/design-system rules.

Research dossiers and source ledgers are audit/maintenance material.

`PERSONA_PERFECT_10_GATE.md` is a **global DesignLab quality rule**, not part of any named designer's persona. It applies to every current and future persona and supersedes any older persona-local readiness threshold such as 4/5. Persona-specific research behaviour remains unchanged.

## Global quality gate

Before any persona submission reaches the user, it must pass `PERSONA_PERFECT_10_GATE.md`:
- ten universal areas;
- 5/5 required in every area;
- no averaging;
- concrete evidence required for every 5;
- any score below 5 blocks submission and triggers revision plus a full rescore.

The gate must not homogenise the personas. It judges quality and integrity; the persona pack determines the design point of view.

## Human approval gates

1. Persona concepts are produced independently from identical Product Truth.
2. Every concept passes the Perfect-10 gate before tournament eligibility.
3. The user reviews eligible concepts and records preferred parts.
4. Opus synthesises one coherent final UX.
5. The user approves and locks UX.
6. Visual directions are produced against the same locked UX and must pass the same global quality gate.
7. The user reviews them and records preferred parts.
8. Opus/visual synthesis creates one coherent final visual system.
9. The user approves and locks visual design.
10. The application is implemented once, then compared against the approved specification.
