# Persona Test Suite

The persona system passes only if the same product truth generates materially different, defensible solutions.

## Test fixtures
1. Messaging inbox/thread.
2. Map discovery.
3. Onboarding.
4. Camera/post flow.
5. Feed.
6. Profile.
7. Complex settings.

## Pass criteria
Each persona must:
- preserve identical product truth;
- propose a meaningfully different decision strategy;
- avoid copying known products;
- avoid invented backend capabilities;
- expose trade-offs;
- include accessibility;
- remain implementable;
- avoid caricature.

## Failure signals
- four proposals differ only in colours/fonts;
- persona name could be swapped with no change;
- signature gimmicks dominate the concept;
- proposals invent features;
- important actions rely only on hidden gestures;
- the concept works only in a hero screenshot.
