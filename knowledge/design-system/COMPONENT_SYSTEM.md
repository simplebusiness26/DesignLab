# Component System

For each component document:
- purpose;
- anatomy;
- variants;
- states;
- dimensions/tokens;
- interaction behavior;
- motion;
- accessibility;
- when to use;
- when not to use.

Minimum inventory:
buttons, icon buttons, inputs, search, navigation, tabs, sheets, dialogs, menus, cards, list rows, feeds, message bubbles, composer, avatars, badges, toasts, loaders, error states and empty states.
